Три знака

Один продукт, три характера. Основной кандидат — «Коробка-метка»: он связывает место, коробку и NFC в один узнаваемый жест.

A / Коробка-метка

Наклейка на коробке превращается в указатель. Хорошо работает в маленьком размере.

SVG192512Maskable 192Maskable 512

B / Полки

Модульная сетка из двух полок. Более системный знак для больших каталогов.

SVG192512Maskable 192Maskable 512

C / Индекс

Две карточки индекса с контрастной точкой. Самый типографичный вариант.

SVG192512Maskable 192Maskable 512
