# «Где что»: карманный каталог

[Открыть макеты](index.html) · [PNG 390 × 844](png/)

Идея: тёплая бумага, чернильный текст, терракотовая метка. Вещь и её место читаются как запись в каталоге, а главное действие всегда близко к большому пальцу. В `index.html` есть три SVG-логотипа, PWA-иконки для каждого (192, 512 и maskable), светлая и тёмная темы, токены, stroke-иконки, состояния контролов и восемь экранов. Страница открывается локально без сервера и сетевых ресурсов. `?screen=box` показывает один экран, `&theme=dark` включает тёмную тему.

Главные отличия от текущего интерфейса:

- Поиск поднят в начало главной; нижняя панель остаётся простой и удобной для большого пальца.
- У коробки выделены название, место, ID и количество; «Взять» доступно прямо в строке вещи.
- У карточки вещи фото, общий запас и конкретное место видны до раскрывающихся деталей.
- Количество и проект при взятии собраны в нижнем листе с явным остатком в коробке.
- Система строится на одном акцентном цвете, крупных целях касания и проверенных контрастных парах.

Сначала стоит внедрить токены, иконки и нижнюю панель; затем главную с поиском, коробку и лист «Забрать». Значения вещей в макетах демонстрационные, на основе подсказок из `profiles/default.yaml`; названия полей и действий сверены с шаблонами приложения.
