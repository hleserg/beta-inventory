# «Где что»: спокойный поиск вещей

[Открыть макеты](index.html) · [PNG 390 × 844](png/) · [Правило названий](NAMING.md) · [Камера: QR и AR](CAMERA.md)

Идея: чистая светлая поверхность, глубокий синий для обычных действий, красный только для опасных. Макеты можно открыть без сервера; кнопки «Взять», «Вернуть» и «Списать» в карточке показывают нижние листы. `?screen=item` открывает карточку отдельно, `&theme=dark` включает тёмную тему.

Главные отличия от текущего интерфейса:

- Названия предметов занимают до трёх строк одинаковой высоты; правило для агента записано в [NAMING.md](NAMING.md).
- Поиск ранжирует вещи и коробки вместе по релевантности, без постоянного приоритета коробок.
- «Взять» находится у конкретной коробки в карточке; «Вернуть» и «Списать» — у запаса на руках. Количество вводится в нижнем листе кнопками или с клавиатуры.
- QR-сканер доступен в нижней панели; NFC работает при поднесении метки, без экранной кнопки.
- Пустой поиск, пустая коробка и пустой каталог имеют разные экраны с одним ясным следующим действием.
- Камера получила крупную рамку для автоматического QR и режим содержимого коробок по видимым наклейкам.

Внедрять сначала палитру и типографику, затем строки с двухстрочными названиями и поиск, после — действия с запасом. Логотипы, PWA-иконки, иконки действий, состояния контролов и экраны собраны в `index.html`. Данные демонстрационные; поля взяты из `profiles/default.yaml` и шаблонов.

Это мобильная итерация. Десктопный интерфейс — после утверждения мобильной версии.
