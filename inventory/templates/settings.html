Как настроить этот телефон

Сайт сам пишет NFC-метки, но Chrome разрешает это только «безопасным» сайтам. Домашний сайт работает без HTTPS, поэтому один раз впишите его в исключения Chrome:

  1. Включите NFC в настройках телефона (найдите «NFC» поиском по настройкам).
  2. Скопируйте и вставьте в адресную строку Chrome — ссылкой такие страницы не открываются:
  3. В пункте «Insecure origins treated as secure» впишите адрес сайта и выберите Enabled:
  4. Нажмите Relaunch внизу экрана: Chrome перезапустится.
  5. Установите приложение: меню Chrome ⋮ → «Добавить на главный экран» (или «Установить приложение»). Метка, поднесённая к закрытому телефону, всё равно откроется в Chrome: без HTTPS Android не отдаёт ссылки приложению. А при открытом сайте метка сразу откроет свою коробку или вещь — «Разрешить» выше.

«Записать на метку» отвечает «Этот браузер не пишет метки»? Откройте сайт именно в Chrome: Samsung Internet и Firefox метки не пишут. Адрес в пункте 3 должен совпадать с адресом сайта в строке браузера.

На iPhone сайты не могут записывать NFC-метки, Apple не даёт им такой возможности. Метку запишет бесплатное приложение NFC Tools.

NFC Tools в App Store

  1. На странице коробки откройте «Настроить, наклейка» (на карточке вещи — «Метка») и скопируйте «Ссылку для NFC-метки».
  2. В NFC Tools: Write (Запись) → Add a record (Добавить запись) → URL / URI → вставьте ссылку → OK.
  3. Нажмите Write и поднесите метку к верхнему краю iPhone.

Приложение на экран: Safari → «Поделиться» → «На экран „Домой“».
